١. العمليات الحسابية — Arithmetic Operators

في C++ عندنا 5 عمليات حسابية أساسية:

العمليةالرمزمثالالنتيجة
الجمع — Addition+f + 7قيمة f + 7
الطرح — Subtraction-p - cقيمة p - c
الضرب — Multiplication*b * mقيمة b × m
القسمة — Division/x / yناتج قسمة x على y
باقي القسمة — Modulus%r % sباقي قسمة r على s

نقاط مهمة:

⚠️ Integer Division — القسمة الصحيحة لما بتقسم عدد صحيح على عدد صحيح، النتيجة بتتقلبط (الكسر بيتشال).
7 / 5 = 1 مش 1.4
10 / 3 = 3 مش 3.33
💡 عملية Modulus % بترجع باقي القسمة. مثلاً:
7 % 5 = 2 (لأن 7 = 5×1 + 2)
10 % 3 = 1 (لأن 10 = 3×3 + 1)
⚠️ الـ % بتشتغل فقط مع الأعداد الصحيحة — 7 % 5.0 خطأ!
مثال: تحويل بوصات لأقدام
#include <iostream> using namespace std; int main() { int len, feet, inch; cout << "أدخل الطول بالبوصات: "; cin >> len; feet = len / 12; // عدد الأقدام الكاملة inch = len % 12; // الباقي بالبوصات cout << "feet = " << feet << "\tinch = " << inch; return 0; } // 100 بوصة = 8 أقدام و 4 بوصات // 55 بوصة = 4 أقدام و 7 بوصات

٢. عمليات الاختصار — Shorthand Assignment Operators

بدل ما تكتب x = x + 2; في C++ في طريقة اختصار أسرع وأوضح:

الكتابة الطويلةالاختصارالمعنى
x = x + 2;x += 2;زود x بمقدار 2
x = x - 2;x -= 2;نقص x بمقدار 2
x = x * 2;x *= 2;اضرب x في 2
x = x / 2;x /= 2;قسم x على 2
x = x + 1;x += 1; أو x++; أو ++x;زود x بواحد

٣. Prefix و Postfix — قبل وبعد الزيادة

الفرق بين ++x و x++ بيظهر لما بتستخدمهم جوا Expression (تعبير) أو cout.

++x — Pre-increment (زيادة قبل الاستخدام)

الزيادة بتحصل الأول، وبعدين القيمة الجديدة بتتستخدم

int x = 5; cout << ++x; // يطبع 6 // x أصبح 6 في الذاكرة

x++ — Post-increment (زيادة بعد الاستخدام)

القيمة القديمة بتتستخدم الأول، وبعدين الزيادة بتحصل

int x = 5; cout << x++; // يطبع 5 // x أصبح 6 في الذاكرة

🔍 Trace كامل — تتبع خطوة بخطوة:

int x = 5; // السطر 1: x++; // x = 6 // السطر 2: cout << x++; // يطبع 6 ثم x يصبح 7

Trace لـ Postfix x++:

1
int x = 5; → الذاكرة: x=5
2
x++; → الذاكرة: x=6
3
cout << x++; → يطبع 6 ثم x يصبح 7 في الذاكرة

Trace لـ Prefix ++x:

1
int x = 5; → الذاكرة: x=5
2
++x; → الذاكرة: x=6
3
cout << ++x; → x يصبح 7 أولاً ثم يطبع 7
📌 ملخص سريع ++x = زيد الأول، استخدم بعدين 🔼 قبل
x++ = استخدم الأول، زيد بعدين 🔼 بعد

٦. أولوية العمليات — Operator Precedence

لما في أكتر من عملية في نفس السطر، C++ بتحسبهم في ترتيب معين (زي الرياضيات):

الأولوية (من الأعلى)نوع العمليةالاتجاه
1 — الأعلىPrefix: ++x, --xيمين لشمال
2Unary: ! (NOT)يمين لشمال
3Arithmetic: *, /, %شمال لـ يمين
4Arithmetic: +, -شمال لـ يمين
5Relational: <, >, <=, >=شمال لـ يمين
6Equality: ==, !=شمال لـ يمين
7Logical AND: &&شمال لـ يمين
8Logical OR: ||شمال لـ يمين
9Assignment: =, +=, -=, *=, /=, %=يمين لشمال
10 — الأدنىPostfix: x++, x--—

🔍 Trace أمثلة (x=1, y=2, z=3, w=4):

cout << x + y * z - w;

1
y * z = 2 * 3 = 6 (ضرب أولاً)
2
x + 6 = 1 + 6 = 7
3
7 - w = 7 - 4 = 3 ← الإجابة

cout << x + (z - y) + w / x * y * z - 5;

1
z - y = 3 - 2 = 1 (القوس أولاً)
2
w / x = 4 / 1 = 4
3
4 * y = 4 * 2 = 8
4
8 * z = 8 * 3 = 24
5
x + 1 + 24 - 5 = 1 + 1 + 24 - 5 = 21 ← الإجابة

cout << --x || y && z; (x=1, y=2, z=3)

1
--x = 0 (x يصبح 0)
2
y && z = 2 && 3 = 1 && 1 = 1
3
0 || 1 = 1 ← الإجابة

٧. جمل التحكم والاختيار — Control / Selection Structures

في برامج C++، الكود بيتنفذ من فوق لتحت بالترتيب — ده اسمه Sequential Execution. بس أحياناً بنحتاج نغير التنفيذ حسب شرط — ده اسمه Transfer of Control.

عندنا نوعين من جمل التحكم:

  • Selection (اختيار): if, else, switch — نختار أي كود يتنفذ
  • Repetition (تكرار): for, while, do-while — سنذكرها في محاضرات قادمة
🔀

٨. جملة if — الجملة الشرطية

One-Way Selection — شرط من طرف واحد:

if (الشرط) تعليمة_واحدة; if (الشرط) { تعليمة1; تعليمة2; }

Two-Way Selection — شرط من طرفين:

if (الشرط) تعليمة_لو_صح; else تعليمة_لو_غلط;
مثال — فردي أم زوجي؟
#include <iostream> using namespace std; int main() { int x; cout << "أدخل رقماً: "; cin >> x; if (x % 2 == 0) cout << "زوجي (even)"; else cout << "فردي (odd)"; return 0; }

Multiple Selection — أكتر من شرط:

if (الشرط الأول) تعليمة1; else if (الشرط الثاني) تعليمة2; else if (الشرط الثالث) تعليمة3; else تعليمة_افتراضية;
مثال — فحص الحروف المتحركة
char alpha; cout << "أدخل حرفاً: "; cin >> alpha; if (alpha == 'a' || alpha == 'e' || alpha == 'i' || alpha == 'o' || alpha == 'u') cout << "حرف متحرك (vowel)"; else cout << "حرف ساكن (consonant)";
مثال — أكبر 3 أرقام
int x, y, z, max; cin >> x >> y >> z; if (x > y) max = x; else max = y; if (z > max) max = z; cout << "الأكبر = " << max;

٩. العملية الثلاثية — Ternary Operator

طريقة مختصرة لكتابة if/else في سطر واحد. الصيغة هي:

variable = (الشرط) ? قيمة_لو_صح : قيمة_لو_غلط;

الطريقة العادية بـ if/else

int time = 20; if (time < 18) { cout << "Good day"; } else { cout << "Good evening"; }

بالـ Ternary Operator

int time = 20; string result = (time < 18) ? "Good day" : "Good evening"; cout << result;
📌 متى تستخدم Ternary؟ لو الـ if/else بسيط وفيه قيمة واحدة في كل حالة. لو الكود معقد، أحسن تستخدم if/else العادية لأنها أوضح.
