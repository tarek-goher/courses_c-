01
for Loop
حلقة for — متى تعرف عدد التكرارات
📌 المفهوم | Concept

حلقة for تُستخدم لما تعرف عدد التكرارات مسبقاً. بتتكون من 3 أجزاء: التهيئة، الشرط، التحديث.
The for loop is ideal when you know the exact number of iterations. It has 3 parts: initialization, condition, update.

for ( /* Part 1: init */ ; /* Part 2: condition */ ; /* Part 3: update */ )
{
    // body — executed while condition is true
}

🔥 الـ 3 أماكن للـ ++ — The 3 Positions of Increment (University Trap!)

الفرق بين وضع i++ و ++i في أجزاء الـ for هو سلاح الاختبارات الجامعية الأول!

# POSITION Example الشرح بالعربي Behavior
1 Init (Part 1) for(int i=0; i<5; i++) التهيئة — بتتنفذ مرة واحدة بس Normal — runs once
2 Update — i++ for(int i=0; i<5; i++) post-increment: يُرجع القيمة القديمة ثم يزيد Uses old value, then adds 1
3 Update — ++i for(int i=0; i<5; ++i) pre-increment: يزيد أولاً ثم يُرجع القيمة Adds 1 first, then uses
! Inside body for(int i=0; i<5; ) { cout << i++; } الـ increment جوه الـ body نفسه — خطير! Most dangerous — tricky output
C++ — i++ vs ++i in update 
// Both produce SAME output here:
// مخرجات متشابهة في الـ for

for(int i=0; i<5; i++)
    cout << i << " ";
// Output: 0 1 2 3 4

for(int i=0; i<5; ++i)
    cout << i << " ";
// Output: 0 1 2 3 4  ← Same!
C++ — increment INSIDE body (tricky!) 
// ⚠️ Tricky — increment in body!
// الـ ++ جوه الـ body

for(int i=0; i<5; )
{
    cout << i++ << " ";
}
// Output: 0 1 2 3 4

for(int i=0; i<5; )
{
    cout << ++i << " ";
}
// Output: 1 2 3 4 5  ← Different!
C++ — mixed tricks in condition and body 
// 🔥 University Exam Level!
int i = 0;
for( ; i<3; ) {
    i++;                     // i becomes 1,2,3
    cout << i * 2 << " ";  // prints 2 4 6
}
// Output: 2 4 6

for(int x=1; x<=4; x+=2)  // step by 2
    cout << x << " ";
// Output: 1 3
02
Nested for Loop
الحلقة المتداخلة — for داخل for
📌 المفهوم | Concept

حلقة for جوة حلقة for تانية. الـ outer loop بتتحكم في الصفوف والـ inner loop بتتحكم في الأعمدة. لكل تكرارة في الخارجية، الداخلية بتتنفذ بالكامل.
A for loop inside another. The outer controls rows, inner controls columns. For each outer iteration, the inner loop runs completely.

⏱️ Total Iterations

لو outer = n وinner = m فإجمالي التكرارات = n × m
If outer = n and inner = m → total = n × m iterations

🔢 Variable Scope

متغير الـ outer loop مش موجود في الـ inner بـ scope منفصل
Outer variable is accessible inside inner loop body

C++ — Multiplication Table 
// جدول الضرب — Multiplication Table
for(int i=1; i<=3; i++) {
    for(int j=1; j<=3; j++) {
        cout << i*j << "\t";
    }
    cout << "\n";
}
/* Output:
   1  2  3
   2  4  6
   3  6  9  */
C++ — Star Pattern (Triangle) 
// مثلث من النجوم — Star Triangle
for(int i=1; i<=4; i++) {
    for(int j=1; j<=i; j++) {
        cout << "* ";
    }
    cout << "\n";
}
/* Output:
   *
   * *
   * * *
   * * * *  */
C++ — Tricky nested: variable shared between loops 
// 🔥 Tricky: inner loop uses outer variable
for(int i=1; i<=3; i++) {
    for(int j=i; j<=3; j++) {  // j starts from i!
        cout << j << " ";
    }
    cout << "\n";
}
/* Output:
   1 2 3
   2 3
   3       */
03
while Loop
حلقة while — بتفحص الشرط قبل التنفيذ
📌 المفهوم | Concept

حلقة while بتفحص الشرط الأول قبل ما تنفذ أي حاجة. لو الشرط false من الأول — مش هتتنفذ خالص (zero times possible!).
The while loop checks its condition BEFORE executing. If false from the start — it never runs (0 executions possible).

while ( condition )
{
    // body — executed while condition is true
    // ⚠️ must update variable inside or = infinite loop!
}
C++ — Basic while 
// Basic while loop
int i = 0;
while(i < 5) {
    cout << i << " ";
    i++;  // ← MUST update!
}
// Output: 0 1 2 3 4

// Zero executions example:
int x = 10;
while(x < 5) {  // false from start!
    cout << x;   // never runs!
}
// Output: (nothing)
C++ — while with tricky increment 
// 🔥 Tricky: post vs pre increment
int n = 1;
while(n++ < 4)  // checks THEN increments
    cout << n << " ";
// Checks 1<4 → true, n becomes 2, prints 2
// Checks 2<4 → true, n becomes 3, prints 3
// Checks 3<4 → true, n becomes 4, prints 4
// Checks 4<4 → false, n becomes 5, stops
// Output: 2 3 4
04
do-while Loop
حلقة do-while — بتنفذ الأول وبعدين تفحص
📌 المفهوم | Concept

حلقة do-while بتنفذ الـ body الأول، وبعدين تفحص الشرط. دي الفرق الجوهري عن while — بتضمن تنفيذ مرة واحدة على الأقل دايماً.
The do-while runs the body FIRST, then checks the condition. Guaranteed to execute at least ONCE unlike while.

do
{
    // body — runs at least once guaranteed!
} while ( condition ) ; // ← don't forget semicolon!
C++ — do-while runs at least once 
// Even if condition is false — runs once!
int i = 10;
do {
    cout << i << " ";
    i++;
} while(i < 5);  // false from start!
// Output: 10  (ran ONCE!)

int k = 0;
do {
    cout << k << " ";
    k++;
} while(k < 4);
// Output: 0 1 2 3
C++ — Menu system (real use case) 
// Perfect use case: menu loop
int choice;
do {
    cout << "1.Add 2.Delete 3.Exit\n";
    cout << "Enter choice: ";
    cin >> choice;

    if(choice == 1)
        cout << "Adding...\n";

} while(choice != 3);
// Keeps showing menu until user picks 3
