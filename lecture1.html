٢. ازاي بيشتغل البرنامج — How a Program Runs

المراحل من الكود للتشغيل:

  • Source Code: الكود اللي إنت كاتبه بـ C++
  • Compiler: بيترجم الكود لـ Machine Language (اللغة اللي الكمبيوتر يفهمها)
  • Object Code: الكود المترجم
  • Linker: بيجمع الكود بتاعك مع مكتبات جاهزة (زي cout و cin)
  • Execution: التشغيل الفعلي

أنواع الأخطاء:

❌ Syntax Errors — أخطاء في الكتابة خطأ في قواعد اللغة — الـ Compiler بيكتشفها. مثال: نسيت فاصلة منقوطة ;
⚠️ Run-time Errors — أخطاء وقت التشغيل البرنامج بيتترجم لكن لما بتشغله بيحصل خطأ. مثال: القسمة على صفر.
🔎 Logic Errors — أخطاء منطقية البرنامج بيشتغل بس النتيجة غلط! ده أصعب نوع لأن الكمبيوتر مش بيحس إنه فيه خطأ.

٣. تاريخ C++ ومين بيستخدمه

  • لغة C اتصنعت على يد Dennis Ritchie في AT&T Bell Labs في السبعينات — كانت بتستخدم في صيانة UNIX
  • لغة C++ صنعها Bjarne Stroustrup في الثمانينات — زادت عليها Object-Oriented Programming
  • C لسه موجودة جوا C++ (C is a subset of C++)

C++ بتتستخدم فين؟

  • 🎮 تطوير الألعاب: Unreal Engine, Unity
  • 💻 أنظمة التشغيل: Windows, Linux
  • 📡 الأنظمة المضمنة (IoT, microcontrollers)
  • 🔬 التطبيقات العلمية والهندسية
  • 📈 أنظمة التداول المالي عالية السرعة

٤. هيكل برنامج C++ — Program Structure

أي برنامج C++ لازم يكون فيه الهيكل ده:

هيكل البرنامج الأساسي
#include <iostream> using namespace std; int main() { // المتغيرات هنا // التعليمات هنا return 0; }

شرح كل جزء:

  • #include <iostream> — بيضيف مكتبة الـ Input/Output عشان نقدر نستخدم cout و cin
  • using namespace std; — بيخلينا نكتب cout و cin من غير std:: قبليهم
  • int main() — أي برنامج C++ لازم فيه main function — من هنا بيبدأ التشغيل
  • return 0; — معناه البرنامج خلص وكل حاجة تمام
  • ; كل تعليمة لازم تنتهي بفاصلة منقوطة
📌 قاعدة مهمة كل statement في C++ لازم ينتهي بـ ; وكل برنامج لازم يحتوي على main function

٥. التعليقات — Comments

التعليقات بيكتبها المبرمج للشرح — الكمبيوتر بيتجاهلها تماماً.

نوعان من التعليقات
// تعليق على سطر واحد // هذا برنامجي الأول بلغة C++ /* تعليق على أكثر من سطر يمكن استخدامه للشرح المطول */ int x = 5; // x تساوي 5
💡 لماذا نستخدم التعليقات؟ لما تفتح الكود بعد شهر، التعليقات بتساعدك تفهم إيه اللي عملته. وكمان بتساعد أي حد تاني يشتغل على كودك.

٦. الإخراج — Output باستخدام cout

cout (اختصار Character Output) بنستخدمه عشان نطبع على الشاشة. بنستخدم معاه الإشارة <<

مثال على cout
cout << "Hello World"; cout << "اسمي Ahmed"; cout << 5 + 6; // هيطبع 11 cout << "hi" << " " << "everyone";

Escape Sequences — رموز التنسيق:

الرمزالمعنىمثال
\nسطر جديد (New Line)cout << "سطر1\nسطر2";
\tمسافة كبيرة (Tab)cout << "اسم\tعمر";
\\شرطة مائلة \cout << "\\";
\"علامة تنصيصcout << "\"";
endl vs \n
cout << "السطر الأول" << "\n"; cout << "السطر الثاني" << endl; // الاثنين بيعملوا نفس الحاجة — endl أوضح
مثال كامل — Hello World
#include <iostream> using namespace std; int main() { cout << "Hello World" << endl; return 0; }

٧. المتغيرات — Variables

المتغير هو مكان في الذاكرة بنخزن فيه بيانات. المتغير ليه اسم و نوع و قيمة.

طريقة تعريف المتغيرات
int x; // متغير من نوع int بدون قيمة float num = 0.58; // متغير float بقيمة ابتدائية char c = 'A'; // متغير char — القيمة بين ' ' bool b, b2, b3; // تعريف أكتر من متغير int r, y, i = 0; // فقط i بيأخد قيمة 0

قواعد تسمية المتغيرات:

  • ✅ يبدأ بحرف أو underscore _ (مش رقم)
  • ✅ يحتوي على حروف وأرقام وـ _
  • ✅ حساس لحالة الأحرف: x و X متغيرين مختلفين
  • ❌ ما ينفعش يكون اسمه كلمة محجوزة (int, if, else, main...)
  • ❌ ما ينفعش يبدأ برقم (مثل 3x, 4r)
  • ❌ ما يحتويش على رموز خاصة (@ # $ % ^)
❌ أمثلة على أسماء غلط: char 4r; — يبدأ برقم  |  double main; — main كلمة محجوزة  |  int x=5; float x; — إعادة تعريف نفس المتغير
✅ أمثلة على أسماء صح: x, myAge, total_sum, _count, num1, firstName

const — الثوابت:

لو عندك قيمة ما هتتغيرش، استخدم const

const int PI_VALUE = 3; const char GRADE = 'A'; // PI_VALUE = 5; خطأ! ما تقدرش تغير الثوابت

٨. أنواع البيانات — Data Types

كل متغير له نوع بيحدد إيه البيانات اللي يقدر يخزنها وكام مساحة بيأخدها في الذاكرة.

النوعالوصفالحجممثال
intأعداد صحيحة4 bytesint x = 5;
floatأعداد عشرية (~7 أرقام)4 bytesfloat f = 3.14;
doubleأعداد عشرية دقيقة (~15 رقم)8 bytesdouble d = 3.14159;
charحرف واحد1 bytechar c = 'A';
boolقيمة منطقية true/false1 bytebool b = true;
shortعدد صحيح صغير2 bytesshort s = 100;
longعدد صحيح كبير4 byteslong l = 999999;

Type Casting — تغيير النوع:

أحياناً بنضطر نحول من نوع لتاني

int x = 1, y = 2; double r1 = x / y; // ناتج = 0.0 (قسمة عدد صحيح!) double r2 = double(x) / y; // ناتج = 0.5 ✅ double r3 = x / double(y); // ناتج = 0.5 ✅ int cents = int(r2 * 100); // ناتج = 50
💡 انتبه من Integer Division لو قسمت عدد صحيح على عدد صحيح، الناتج بيتقلبط (truncate). 7/5 = 1 مش 1.4. عشان تاخد الكسر، حول واحد منهم لـ double.

٩. الإدخال — Input باستخدام cin

cin (Character Input) بنستخدمه عشان نقرأ من المستخدم. بنستخدم معاه >> بدل <<

int num; cout << "أدخل رقماً: "; cin >> num; cout << "الرقم هو: " << num;

قراءة أكتر من متغير:

int x, y, z; cin >> x >> y >> z; // المستخدم يكتب: 10 20 30 ثم Enter
مثال كامل — جمع 3 أرقام
#include <iostream> using namespace std; int main() { int num1, num2, num3, sum; cout << "أدخل 3 أرقام: "; cin >> num1 >> num2 >> num3; sum = num1 + num2 + num3; cout << "المجموع = " << sum << endl; cout << "المتوسط = " << sum / 3 << endl; return 0; }
