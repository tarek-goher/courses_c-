LECTURE 3

الجمل الشرطية المتداخلة & Switch

Nested if-else — Switch Statement — Break & Default

🔀

Nested If — الـ if المتداخل

الـ Nested if هو ببساطة إنك تحط if جواه if تاني. ده بيخليك تفحص أكتر من شرط على التسلسل.

الصيغة (Multiway if-else)

if (Boolean_Expression_1) Statement_1 else if (Boolean_Expression_2) Statement_2 // ... ممكن أكتر else if (Boolean_Expression_n) Statement_n else Statement_For_All_Other_Possibilities

مثال 1 — تحقق من الإشارة

int x; cout << "أدخل رقم: "; cin >> x; if(x < 0) cout << "-ve"; else if(x > 0) cout << "+ve"; else cout << "zero";

مثال 2 — نظام الدرجات

int score; cin >> score; if(score >= 85) cout << "Excellent"; else if(score >= 75) cout << "Very Good"; else if(score >= 65) cout << "Good"; else if(score >= 50) cout << "Pass"; else if(score >= 0) cout << "Fail"; else cout << "Invalid";
⚡ ملاحظة مهمة: في الـ else-if المتسلسلة، بمجرد ما شرط واحد يتحقق، باقي الشروط مش بتتفحص — ده بيخلي الكود أسرع وأوفر.
🎛️

Switch Statement — جملة التبديل

الـ switch بيستخدم لما عندك متغير وعايز تقارنه بقيم ثابتة محددة. هو بديل للـ else-if المتعددة بشكل أنيق.

الصيغة

switch (controlling_expression) { case Constant_1: Statement_Sequence_1; break; case Constant_2: Statement_Sequence_2; break; // ... default: Default_Statement; }

الأنواع المسموح بها في switch

  • int — أعداد صحيحة
  • char — حرف واحد
  • bool — true/false (1/0)
  • enum — قيم مخصصة
  • ❌ float/double — غير مسموح! الكود مش هيكمبايل

مثال — آلة حاسبة

char op; int a, b; cin >> a >> b >> op; switch(op) { case '+': cout << a+b; break; case '-': cout << a-b; break; case '*': cout << a*b; break; case '/': if(b == 0) cout << "Error: div by zero"; else cout << a/b; break; default: cout << "Invalid operator"; }

تجميع الـ cases (Fallthrough مقصود)

switch(ch) { case 'a': case 'e': case 'i': case 'o': case 'u': cout << "Vowel"; break; default: cout << "Consonant"; }
💡 لو نسيت الـ break، البرنامج هيكمل في الـ case التالي (Fallthrough) — ده في الغالب بيكون خطأ لو مش متعمد!
⚖️

يقبل float/doubleلا يقبل float/double

⚠️

أخطاء شائعة ومزالق

  • نسيان الـ break في switch → Fallthrough غير مقصود
  • وضع فاصلة منقوطة بعد switch(x); → switch بجسم فاضي = بيتجاه كل الـ cases
  • استخدام float في switch → Compile error
  • case c بدون single quotes → يتعامل معه كمتغير مش كحرف — Compile error
  • score=50 في المثال: if(score>=85) false → else { if(score>=75) false → cout<<" and not excellent" } → output: " and not excellent" ثم "program finishes"
LECTURE 4

جمل التكرار Loops

while — do-while — for — break — continue — Nested Loops

🔁

مقدمة — أنواع الحلقات

الـ loop بيتيح إنك تكرر كود معين عدد من المرات أو لحد ما شرط معين يتحقق. في C++ عندنا 3 أنواع:

  • while — يفحص الشرط أولاً قبل ما يدخل
  • do-while — ينفذ مرة واحدة على الأقل، يفحص الشرط في الآخر
  • for — مناسب لما عارف عدد التكرارات مسبقاً

كل loop عنده 4 مكونات: Initialization (بداية العداد) | Condition (الشرط) | Body (الجسم) | Step/Update (التحديث)

⚙️

while Loop

الصيغة

initialization; while (boolean_expression) { statements_to_repeat; update/step; }

كيف يشتغل: يفحص الشرط أول → لو false يخرج فوراً → لو true ينفذ الجسم → يرجع يفحص الشرط → يكرر لحد ما الشرط يبقى false.

⚠️ الـ while ممكن ما يتنفذ خالص لو الشرط false من الأول!

مثال — طباعة 1 إلى 5

int i = 1; while(i <= 5) { cout << i; i++; } // Output: 12345

نسخة مختصرة (Single Statement)

int i = 1; while(i <= 5) cout << i++; // i++ يطبع أولاً ثم يزيد
🔂

do-while Loop

الصيغة

initialization; do { statements_to_repeat; update/step; } while(boolean_expression); // ← لا تنسى الفاصلة المنقوطة!

كيف يشتغل: ينفذ الجسم مرة أولاً → يفحص الشرط → لو true يرجع ينفذ → لو false يخرج.

✅ الـ do-while دايماً بينفذ مرة واحدة على الأقل حتى لو الشرط false من الأول!

استخدام عملي — Perfect Number Checker

char ch; do { int num, sum = 0; cout << "Enter a number: "; cin >> num; int i = 1; while(i <= num/2) { if(num % i == 0) sum += i; i++; } if(sum == num) cout << num << " is perfect\n"; else cout << num << " is NOT perfect\n"; cout << "Try another? (y/n): "; cin >> ch; } while(ch == 'y' || ch == 'Y');
🔢

for Loop

الصيغة

for (initialization; condition; update) { body; }

الـ for loop بيجمع الـ initialization والـ condition والـ update في سطر واحد — بيكون أنسب لما عارف عدد التكرارات من الأول.

مثال — جمع الأعداد من a إلى b

int a, b, sum = 0; cin >> a >> b; for(int x = a; x <= b; x++) sum += x; cout << sum;

while مقابل for — نفس الكود

// while version sum = 0; n = 1; while(n <= 10) { sum += n; n++; } // for version — أنظف وأقصر sum = 0; for(n = 1; n <= 10; n++) sum += n;

مثال — الأعداد الزوجية من 300 إلى 1000

for(int x = 300; x <= 1000; x += 2) cout << x << "\t";
⚖️

⏹️

break & continue

break — الخروج الفوري من الـ loop

for(int a = 2; a < num/2; a++) { if(num % a == 0) { isPrime = 0; break; // خرج من الـ loop فوراً } }
⚡ في الـ nested loops، الـ break بيخرج من الـ loop الداخلي فقط — مش من الكل!

continue — تخطي الـ iteration الحالية

for(int i = 0; i < 50; i++) { if(i % 5 == 0) continue; // تخطى الأرقام المقسومة على 5 cout << i << "\t"; }
💡 continue بيتخطى باقي الكود في الـ iteration الحالية ويروح للـ iteration الجاية مباشرة.
🔲

Nested Loops — الحلقات المتداخلة

الـ nested loop هو loop جوه loop. كل مرة الـ outer loop بيمشي خطوة، الـ inner loop بيكمل كل تكراراته.

مثال — مثلث أرقام

for(int l = 1; l <= 5; l++) { for(int n = 1; n <= l; n++) cout << n; cout << endl; } // Output: // 1 // 12 // 123 // 1234 // 12345

مثال — مثلث نجوم مرتكز

for(int l = 1; l <= 5; l++) { for(int n = 1; n <= 5-l; n++) cout << " "; // مسافات for(int s = 1; s <= 2*l-1; s++) cout << "*"; // نجوم cout << endl; } // Output: // * // *** // ***** // ******* // *********
♾️

Infinite Loop — حلقة لا نهائية

الـ infinite loop هو loop مش بيوقف — بيحصل لما الشرط ما بيبقاش false أبداً.

// خطأ! x دائماً فردي فمش بيوصل 12 أبداً x = 1; while(x != 12) // ← يجب تكون: x < 12 { cout << x << endl; x = x + 2; }
⚠️ دايماً تأكد إن الـ loop body فيها سطر هيخلي الشرط يبقى false في النهاية!
